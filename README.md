# yatakawa
Yatakawa, a golfing language
This language is still sensitive, it's in early-development, expect a Crash after invalid code (I added 28 SyntaxError handling and it wasn't enough)
Command list :
A - tells the compiler to read the next number as X characters, syntax : A235, A2 says it to read 2 characters one-time, and 35 pushes 35 onto the compiler memory
0 to 9 - numeric stuff
, - prints
Strings - "Hello, this is multi linguistical, 你好这是多语言的"
pi - q
eulers - w
tau - e
Empty string - ô
Print the entire compiler memory - ¶
Print no newline - %
Input - ?
Ż - vowels, aeiou
ż - push consonants into compiler memory, bcdfghjklmnpqrstvwxyz
Ź - numbers, 1234567890
ź - uppercase alphabet in order
Ž - latin ext. abcdefghijklmnopqrstuvwxyzėêëēèęéōøœõòôöóäæãåāąáàâśßšłżźžçćčñń
ž - lowercase alphabet in order
ण - reverse string
Л - length of string
: - Push Hello, World! Onto the cm
## - true boolean
> - false boolean
C[N] - compiler memory indexing
N - negative the number last in the cm
One-character at a time, "Hello, World!",2,5,25,A225,ô,q,w,e,¶
